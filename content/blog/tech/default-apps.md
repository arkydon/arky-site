- Smart launcher - Customisable **home launcher** + I can paste any images to the homescreen (like stickers)

- MiXplorer - Very light, small, ad-free, feature packed **file manager**

- [KDE Connect](https://play.google.com/store/apps/details?id=org.kde.kdeconnect_tp&hl=en_IN) - **Connect Android to windows** to share files, control mouse, music, keyboard, system shutdown, etc.

- [Rush](https://github.com/shub39/Rush) : Create beautiful **lyrics cards**

- SkyMap - **Identify stars**, planets, and constellations in the night sky.

- Dagger - **Dota** tournament stats

- Bitwarden - Password manager

### Media

- Adobe Lightroom - Editing RAW images.
- InShot - Mostly used simple video editing and quick image edits
- F-Stop - Photo gallery makes it easy to add tags, batch rename, has a customisable grid view,etc
- Gramophone - A beautiful open-source music player that supports Monet theming.
- Compress Image - Compress images to save space without sacrificing quality.
- [Sponge Cleaner](https://play.google.com/store/apps/details?id=com.prismtree.sponge&hl=en_IN) : Tinder style gallery cleaner.
- Snapseed - Feature pack image editor, not so great for RAW editing.

### Internet

- Brave - resource efficient native adblocker is as good as uBlock & better than other native blockers 
- Windy : Weather radar maps, satellite animations
- Kiwi Browser - Outdated & unmaintained. Used only for dev tools.
- Via Browser - A lightweight browser with resource sniffer, view Source, user-Agent, user Scripts support, customisable Reader Mode, Save page as PDF, Network Log.
- ProtonVPN - Free and private VPN from a relatively reliable company.
- TodayWeather - Weather app with a large number of weather data sources. (dev gave me a free premium code)
- Instaprime: Instagram mod. Removes ads and enables downloads. 

### Writing & notes

- [Appflowy](https://play.google.com/store/apps/details?id=io.appflowy.appflowy&hl=en_IN) : A faster notion alternative. Mostly used for journaling and diary keeping. 
- Google Keep - Simple  note taking terrible for organising to many notes

### Storing

- Nicemind - Mind maps
- Remember the Milk - Make and store todos + many types of lists.
- Memento database - Using this to store playlists of albums in diff categories. I would just use YTM if it had folder support but it doesn't.
- iNaturalist - An app for recording observations of plants, animals, insects
- [Paperspan](https://play.google.com/store/apps/details?id=com.paperspan): Store web article links. (Pocket is dead).
- Hurry - Beautiful app for storing events with countdowns displayed
- Photok - Store, lock & hide images

### Downloading

- YMusic - Youtube video downloader and converter. 
- Fossify - FDroid client. Store for installing safe open source apps.

### Other apps
- GBoard keybaord (terrible I only use it because of the GIF board and Emoji kitchen)
- **Mail** - Tuta, Proton, Gmail
- **Online storage** - Google Photos + Drive, Onedrive, Proton Drive
- **Socials** - Instagram, Twitter, Whatsapp, Twitch
- Youtube Music
